# Thesis Reference Audit Contract Test

A thesis reference audit passes when it:

- parses numeric citations, ranges, comma lists, and full-width bracket variants
- detects uncited bibliography entries and dangling in-text citations
- records a verification status for every bibliography item
- limits or justifies web references
- renumbers in-text citations and bibliography entries together
- reports claims that lost citation support after deletion or replacement

It fails if it only formats the bibliography without checking citation placement and source authenticity.
