# GB/T 7714-2015 参考文献格式

顺序编码制，正文中按引用顺序编号 [1][2][3]...

## 文献类型标识

| 类型 | 标识 | 说明 |
|------|------|------|
| 专著 | [M] | Monograph |
| 期刊文章 | [J] | Journal |
| 学位论文 | [D] | Dissertation |
| 会议论文 | [C] | Conference |
| 电子文献 | [EB/OL] | Electronic Bulletin / Online |
| 标准 | [S] | Standard |
| 报告 | [R] | Report |
| 报纸文章 | [N] | Newspaper |
| 专利 | [P] | Patent |

## 格式模板

### 专著 [M]

```
[序号] 作者. 书名[M]. 版次(第1版不写). 出版地: 出版社, 出版年: 页码.
```

**示例：**
```
[1] 吴功宜. 计算机网络[M]. 第4版. 北京: 清华大学出版社, 2019: 45-67.
[2] Goodfellow I, Bengio Y, Courville A. Deep learning[M]. Cambridge: MIT Press, 2016: 200-230.
```

### 期刊文章 [J]

```
[序号] 作者. 文章题目[J]. 期刊名, 年, 卷(期): 页码.
```

**示例：**
```
[3] 李明, 王华. 基于深度学习的目标检测方法综述[J]. 计算机学报, 2022, 45(8): 1640-1672.
[4] He K, Zhang X, Ren S, et al. Deep residual learning for image recognition[C]//Proceedings of the IEEE Conference on Computer Vision and Pattern Recognition. Las Vegas: IEEE, 2016: 770-778.
```

### 学位论文 [D]

```
[序号] 作者. 论文题目[D]. 保存地: 保存单位, 年份.
```

**示例：**
```
[5] 张伟. 智能家居系统的设计与实现[D]. 合肥: 中国科学技术大学, 2023.
```

### 会议论文 [C]

```
[序号] 作者. 论文题目[C]//会议论文集名. 出版地: 出版者, 年: 页码.
```

**示例：**
```
[6] Vaswani A, Shazeer N, Parmar N, et al. Attention is all you need[C]//Advances in Neural Information Processing Systems. Long Beach: Curran Associates, 2017: 5998-6008.
```

### 电子文献 [EB/OL]

```
[序号] 作者. 标题[EB/OL]. (发布日期)[引用日期]. URL.
```

**示例：**
```
[7] 中华人民共和国教育部. 高等学校人工智能创新行动计划[EB/OL]. (2018-04-02)[2024-03-15]. http://www.moe.gov.cn/xxx.
[8] TensorFlow. TensorFlow documentation[EB/OL]. [2024-01-10]. https://www.tensorflow.org/guide.
```

### 标准 [S]

```
[序号] 标准编号, 标准名称[S]. 出版地: 出版者, 年.
```

**示例：**
```
[9] GB/T 7714-2015, 信息与文献 参考文献著录规则[S]. 北京: 中国标准出版社, 2015.
```

## 作者著录规则

1. **3人及以下**：全部列出，姓名间用逗号分隔
2. **3人以上**：列前3人，后加 "等" (中文) 或 "et al" (英文)
3. **中文作者**：姓名全称
4. **英文作者**：姓在前（全称），名缩写，如 `He K, Zhang X`
5. **多个作者**间用逗号分隔

## 正文引用格式

- 单篇引用：`[1]`
- 连续多篇：`[1-3]`
- 不连续多篇：`[1,3,5]`
- 引用位于句末标点前：`...所示[1]。`
- 作者作为主语时：`张三等[1]提出了...`

## 参考文献列表格式

- 标题"参考文献"：黑体，三号，居中
- 条目字体：宋体，五号 (10.5pt)
- 悬挂缩进：序号后内容对齐
- 按引用顺序排列，不分中英文
- 英文文献中的期刊名、书名不斜体（与 APA 不同）
