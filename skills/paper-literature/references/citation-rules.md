# 引用写作规范

## 正文中的引用方式
- **统一格式**：无论文献类型（[J]期刊、[C]会议、[D]学位论文、[M]教材），正文中一律写"作者[编号]做了什么"，**禁止**提及文献类型。文献类型仅在参考文献列表中通过 [J][D][C] 等标识体现。
- **错误示范**：
  - ✗ "李金明在其硕士论文中完成了..."
  - ✗ "张伟的学位论文侧重于..."
  - ✗ "根据王宇的教材[17]..."
  - ✗ "在硕士学位论文层面，..."
- **正确示范**：
  - ✓ "李金明[9]完成了PLC电梯管理控制系统的设计与调试"
  - ✓ "张伟[10]侧重PLC电梯控制系统的整体方案设计"
  - ✓ "金永顺[19]对SVPWM方法进行了系统分析"
- 所有文献在正文中的引用方式与期刊论文完全一致，读者无需知道引用的是论文、教材还是学位论文。

## 引用上标格式（Word导出）
- **正文中的引用标记 [N] 必须设为上标（右上角小字）。** 这是 GB/T 7714 顺序编码制的排版规范。
- **正文中使用纯半角 `[N]`**，不要写 `<sup>[N]</sup>`。HTML `<sup>` 标签在 pandoc 转 docx 时被拆分为 `RawInline(html)` + `Str` + `RawInline(html)`，docx writer 丢弃 RawInline(html)，导致上标失效。
- **引用上标由 Lua filter 统一处理**：thesis.lua 的 Pass 2 (Inlines filter) 用正则 `%[%d[%d,%-]*%]` 匹配半角 `[N]`、`[1-3]`、`[1,3,5]` 等模式，生成 OpenXML `<w:vertAlign w:val="superscript"/>` 实现上标。
- **参考文献列表中的编号使用全角括号 `［N］`**，避免被 Lua filter 误匹配为引用并转上标。示例：`［1］ 作者. 标题[J]. 期刊, 年, 卷(期): 页码.`

### 为什么不能用 `<sup>`

pandoc 内部 AST 将 `<sup>[1]</sup>` 解析为三个独立元素：
1. `RawInline("openxml"或"html", "<sup>")`
2. `Str("[1]")`
3. `RawInline("openxml"或"html", "</sup>")`

docx writer 输出时丢弃 HTML RawInline，Str("[1]") 变成普通文本。Lua filter 在 Pass 2 处理 Str 时无法知道外层是否有 `<sup>` 包裹（因为它只看单个 Str 元素）。因此，**唯一可靠的上标方案是由 Lua filter 直接生成 OpenXML**。

## 参考文献编号规则（GB/T 7714 顺序编码制）
- 按**正文中首次出现的顺序**从 [1] 开始编号，不按类型、年份或字母排序。
- **范围引用**需展开处理：`[4-5]` 意味着 [4] 和 [5] 两篇文献都参与排序。
- 编号必须严格递增：正文中首次出现 [1] 后，下一个新引用必须是 [2]，不能跳号。
- **所有参考文献必须在正文中被引用，不允许出现未引用的"悬空"条目。** 如果某条文献不需要引用，直接删除。
- 修改引用后需重新编号。可用脚本自动化：
  1. 扫描正文，按出现顺序收集所有引用编号（含范围展开）
  2. 建立 old→new 映射
  3. 替换正文中的引用编号，同时处理范围引用的重新格式化
  4. 按新编号重排参考文献列表

## 参考文献真实性验证

- **任务书中的参考文献大概率是 AI 虚构的**，必须逐条通过 WebSearch 验证。验证要素：作者姓名、论文/书籍标题、期刊/出版社、年份、卷期页码。任何一项不匹配即标记为可疑，搜索真实替代。
- **RFC 标准文档 100% 真实可验证**，优先使用 RFC 作为参考文献。RFC 编号可直接在 IETF 网站查证（如 RFC 2328、RFC 4271），格式固定，不存在伪造风险。
- **中文文献偏少时的处理**：如果某技术方向（如网络协议设计）的高质量中文独立研究确实偏少，在论文 1.2 节（国内外研究现状）中主动说明原因，例如："该方向的核心技术标准集中在 IETF RFC 体系和英文期刊中，国内研究多以应用部署和性能优化为主。"不要为了凑数量而使用低质量或不相关的中文文献。

## 参考文献数量与类型分布
- **数量根据学校要求灵活调整**：有的学校要求 15-25 条，有的要求 30-50 条。先确认学校规范再定数量。
- 建议类型分布（以50条为例）：
  - [J] 期刊论文：占主体（25-35条），含中文和英文
  - [M] 教材/专著：5-8条（经典教材，不必追求最新）
  - [C] 会议论文：3-6条（IEEE等正式会议）
  - [D] 学位论文：2-5条（硕士/博士论文，提供学校和年份）
  - [S] 标准：2-4条（国标、行业标准）
  - [EB/OL] 网络资源：1-3条（政策文件等，不宜过多）
