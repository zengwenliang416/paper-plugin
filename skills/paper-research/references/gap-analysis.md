# Research Gap Analysis

From the synthesized review, find what is genuinely unsolved — and whether this work can fill it.

## Gap dimensions

- **Method**: limitations or assumptions every cluster shares.
- **Data**: missing datasets, scales, modalities, or populations.
- **Scenario**: settings or conditions no one has covered.
- **Comparison**: baselines or ablations never run.
- **Contradiction**: clusters that disagree — a disagreement is an opening.
- **Theory**: mechanisms observed but unexplained.

## For each candidate gap

- **Evidence**: which reviewed papers establish the gap (cite the cluster, not a hunch).
- **Reachability**: can this work fill it with available data / method / time?
- **Contribution**: what becomes possible if it is filled.

## Output

A gap list: `gap → supporting evidence → this work's opportunity`. Drop gaps that are real but out of reach; keep the 1–3 that motivate the contribution. Hand the chosen gap to `paper-manuscript-writing` as the contribution framing for the introduction.

## Caution

A gap must be grounded in the reviewed evidence, not asserted. "No one has done X" requires that the review actually covered where X would appear — otherwise it is an unverified claim, the same failure mode the review/verify steps exist to prevent.
