# Paper Assistant

Use this skill for academic-paper and manuscript workflows.

## Workflow

1. Identify the source material first: PDFs, DOCX files, Markdown notes,
   BibTeX, comments, figures, or local project instructions.
2. Preserve the difference between source evidence and inference.
3. Do not fabricate citations, DOIs, page numbers, methods, experiments, or
   results.
4. When editing a manuscript, keep changes scoped to the user's requested
   section unless they ask for a broader rewrite.
5. Prefer structured outputs for research work:
   - bibliographic facts
   - research question
   - method
   - evidence
   - limitations
   - reusable notes

## Output Defaults

- For summaries, lead with the core contribution and evidence.
- For reviews, lead with issues ordered by severity.
- For drafting, mark unsupported claims that need citations.
- For comparison work, use tables only when they make tradeoffs clearer.
